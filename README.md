# 📊 Aprenda Linguagem C - Fundamentos Para Lógica de Programação 🌐
<br>

## 📚 Descrição do Projeto
O código apresentando é referente ao curso "Aprenda Linguagem C - Fundamentos Para Lógica de Programação" da instituição One Day Code pela plataforma da Udemy.
<br>Este repositório oferece uma introdução prática e acessível ao desenvolvimento em C, perfeita para iniciantes, com variáveis, operações matemáticas, condicionais, conectivos lógicos, loops, vetores e matrizes.



Link do curso: https://www.udemy.com/course/c-e-c-fundamentos-para-logica-de-programacao/

## 🖥️ Tecnologia Utilizada
- C
- C++
